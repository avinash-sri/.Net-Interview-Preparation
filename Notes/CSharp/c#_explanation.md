# How C# Code Executes

## Definition

When a C# program is executed, the source code is first compiled into Intermediate Language (IL). The Common Language Runtime (CLR) loads the assembly, and the Just-In-Time (JIT) compiler converts IL into native machine code that the CPU executes.

## Execution Flow

```text
C# Source Code (.cs)
        ↓
C# Compiler (csc)
        ↓
Intermediate Language (IL)
        ↓
Assembly (.dll/.exe)
        ↓
CLR
        ↓
JIT Compiler
        ↓
Machine Code
        ↓
CPU
```

## Key Terms

### C# Compiler
Compiles C# source code into Intermediate Language (IL).

### Intermediate Language (IL)
A platform-independent language generated by the C# compiler.

### CLR (Common Language Runtime)
The execution engine of .NET responsible for memory management, garbage collection, exception handling, security, and JIT compilation.

### JIT (Just-In-Time Compiler)
Converts IL into machine code when the application executes.

## Interview Questions

### What happens when you run a C# program?

The C# compiler compiles source code into IL. The IL is stored in an assembly. The CLR loads the assembly, and the JIT compiler converts IL into machine code, which is then executed by the CPU.

### Why doesn't C# compile directly to machine code?

Because compiling to IL allows the same application to run on different platforms supported by the .NET runtime.

### Why is C# called a managed language?

Because it executes under the CLR, which manages memory, garbage collection, exception handling, and other runtime services.

# Solution (.sln)

## Definition

A Solution is a container that organizes one or more .NET projects into a single workspace.

## Why do we use it?

- Organize related projects
- Manage dependencies
- Build multiple projects together
- Easier collaboration

## Interview Question

Q. What is the difference between a Solution and a Project?

Answer:

A Solution is a container for multiple projects, whereas a Project is the actual application or library containing source code.
